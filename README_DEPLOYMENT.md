# ALSKwela A&E 2027 – Elementary LS4 Life and Career Skills

## Upload to GitHub Pages
1. Create a separate GitHub repository named `alskwela-ls4-life-career-reviewer-elementary`.
2. Unzip this package; upload the **contents**, not the ZIP, into your repository root.
3. In Settings > Pages, select Deploy from branch > main > /(root).
4. Open the published HTTPS URL directly in Android Chrome while online.
5. Reload while connected, confirm the offline-ready status, add it to the Home Screen, then test the installed reviewer in airplane mode.
6. Connect the published URL to the corresponding LS4 Elementary Open Link action in ALSKwela/Glide.

## Installation identity
Full title: Elementary ALS A&E Reviewer LS 4 - Life and Career Skills
Home Screen: Elem A&E LS4 Career
Offline cache: `alskwela-ae2027-elem-ls4life-*`
Local progress keys: `alskwela_elem_ls4life_*`

## Academic content
- 90 questions; Sets A/B/C with 30 each, or randomized balanced trials.
- 13 Life Skills and 17 Career Skills per set.
- 9 Easy, 15 Moderate and 6 Challenging per set.
- All seven numbered competencies in each set.
- Answer options are shuffled to reduce letter patterns.
- Correct-answer feedback, encouraging incorrect-answer feedback and professional Taglish explanations.
- Local PDF report and browser Print/Save as PDF.

## Notes
The questions are independently written practice items aligned with the uploaded 2026 CG, **not official BEA questions**. Review academic accuracy and pilot test them before learner rollout. The first installation requires internet; afterward the cached app is intended to work offline. On some devices, an Android shortcut opens the cached site without a native install prompt. Learner progress is stored on the device and may be lost if browser storage is cleared.
